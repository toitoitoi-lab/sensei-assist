# せんせいアシスト（仮想の児童生徒で支援を学ぶ）

特定の子ではなく、**不特定の児童生徒を想定した仮想の児童生徒**の特性（学年、障害種別、自立活動の6区分27項目の様子など）を入れ、**そのような特性をもつ児童生徒に典型的に考えられる支援**を、AI（Gemini）といっしょに想定しながら**支援を学ぶ**ための道具です。

![せんせいアシストの画面。左に自立活動の項目ごとのスライダー、右に6区分のレーダーチャート](docs/preview.png)

- アプリを開く（スライダーとチャートはそのまま使えます）：https://toitoitoi-lab.github.io/sensei-assist/
- AIの機能を使うには、自分の Google アカウントで [セットアップ](#セットアップ) をしてください（20分ほど・無料）。

## つくった理由

「こういう特性の子には、どんな支援が考えられるだろう」。研修や校内の話し合いでは、この問いを短い時間で具体的に考える場面がよくあります。
架空の児童生徒の特性をスライダーと言葉で置き、典型的な支援の例を並べて見ることで、支援の引き出しを増やし、話し合いの材料にするためにつくりました。

特定の児童生徒の相談に使うと、どうしても個人が分かる情報を入れることになります。そのため、このアプリは**特定の児童生徒の相談には使わず**、仮想の児童生徒を題材に、支援の考え方を学ぶことに目的をしぼっています。

## 大切な約束：実際の児童生徒のデータは入れません

- このアプリに入れるのは、**架空の児童生徒の特性だけ**です。
- **実際の児童生徒のデータは入力しないでください。** 氏名や記号に置きかえても、実在の児童生徒の様子をもとにした入力はしないでください。
- 入力した内容は、自分でデプロイした Google Apps Script を通して Gemini API に送られます。
- 出てくるのは、架空の特性から想定した**典型的な支援の例**です。特定の児童生徒の見立てや指導方針として使うものではありません。
- 画面の「架空の例を入れてみる」で、入力の例を試せます。

### 費用：無料枠で使えます

- **API キーを作るのも、このアプリで使うのも無料です。** このアプリが使う Gemini 3.5 Flash は、Gemini API の**無料枠**で、入力にも出力にも料金がかかりません（[料金のページ](https://ai.google.dev/gemini-api/docs/pricing)）。
- **料金が発生するのは、自分で「有料枠」に切りかえたときだけです。** 有料枠にするには、支払い方法（請求先アカウント）の登録が必要です。Google AI Studio で「請求を設定」「有料にアップグレード」などの案内が出ても、進まなければ無料のままです。
- **無料枠には回数の上限があります。** 短い時間に続けて使うと「APIのレート制限に達しました」と出ます。1分ほど待てば、また使えます。1人で使う程度なら、ふつうは足ります。
- **無料枠では、送った内容が Google の製品改善に使われ、人が読むことがあります。** だからこそ、このアプリには**架空の児童生徒の特性だけ**を入れます。
- 料金や無料枠の内容は変わることがあります。使いはじめる前に、[料金のページ](https://ai.google.dev/gemini-api/docs/pricing)と[利用規約](https://ai.google.dev/gemini-api/terms)を確認してください。

## 合言葉（APP_KEY）とは

このアプリでは、AI とやりとりする部分（GAS）を、各自が自分の Google アカウントに置きます。このとき、2つのものを使います。

| | たとえると | 役割 |
|---|---|---|
| GAS の URL（`…/exec`） | 自分専用の「AI 窓口」の**住所** | アプリがどこへ相談を送るか |
| 合言葉（`APP_KEY`） | その窓口の**入口で言う合言葉** | 相談を送ってきたのが、本当に自分かどうか |

GAS は「アクセスできるユーザー：全員」で公開するので、**住所（URL）を知っている人なら、だれでも窓口に相談を送れてしまいます。** そうすると、自分の API キーが使われたり、自分のドライブにドキュメントが作られたりします。

そこで、窓口に「合言葉を言えた相談だけ受けつける」という決まりをつけます。

```
アプリ ──「相談です。合言葉は ○○○」──▶ GAS（自分の窓口）
                                      ├ 合言葉が APP_KEY と同じ → AI に相談する
                                      └ ちがう・言わない      → 「合言葉が違います」で止める
```

### 合言葉について知っておくこと

- **合言葉は、API キーとは別のものです。**

  | | API キー（`GEMINI_API_KEY`） | 合言葉（`APP_KEY`） |
  |---|---|---|
  | だれが作る | Google（AI Studio で発行してもらう） | 自分（好きな文字列を決める） |
  | 何のため | 自分の GAS が Google の AI を使うための鍵 | 自分のアプリが自分の GAS を使うための合言葉 |
  | どこに入れる | GAS のスクリプト プロパティだけ | GAS のスクリプト プロパティ **と** アプリの「合言葉」欄 |
  | アプリの画面に入れる？ | **入れない** | 入れる |


- **自分で決める文字列です。** Google のパスワードやほかのサイトのパスワードとは別のものにしてください（使い回さない）。
- **同じ文字列を2か所に入れます。**
  1. GAS の「スクリプト プロパティ」の `APP_KEY`（窓口に覚えさせる）
  2. アプリの画面のいちばん下の「合言葉」の欄（アプリが毎回伝える）
- **長くて推測されにくいものにします。** 20文字以上が目安です。単語をいくつかつないで数字を混ぜると、長くても覚えやすくなります（例の形：`kumo-tokei-sora7-hanabi42`。この例そのものは使わないでください）。パスワード管理アプリの「パスワードを生成」を使っても大丈夫です。
- **覚えておかなくても大丈夫です。** アプリの欄に一度入れると、そのブラウザが覚えています。別のパソコンやブラウザで使うときだけ、もう一度入れます。
- **忘れたときは、決め直せます。** GAS の `APP_KEY` の値を新しい合言葉に書きかえて保存し、アプリの欄にも同じものを入れ直してください。
- **人に教えないでください。** 教えると、その人もあなたの窓口を使えるようになります。

## セットアップ

GAS（Google Apps Script）は、Google が用意している、無料でプログラムを動かせるしくみです。ここに AI とやりとりする部分を置きます。

### 1. API キーを作る

1. https://aistudio.google.com/apikey を開き、Google アカウントでログインします。
2. 「API キーを作成」を押します。
3. 表示されたキー（長い英数字）をコピーして、ひとまずメモ帳などに控えます。**このキーは、ほかの人に教えないでください。**

### 2. GAS のプロジェクトをつくる

1. https://script.google.com を開き、左上の「新しいプロジェクト」を押します。
2. 左上の「無題のプロジェクト」を押して、名前を「せんせいアシスト」などに変えます。
3. 画面の `コード.gs` の中身を全部消し、このリポジトリの [`Code.gs`](Code.gs) の中身を全部コピーして貼りつけます。
4. ⌘S（Windows は Ctrl+S）で保存します。

### 3. API キーと合言葉を登録する（スクリプト プロパティ）

**コードの中には書きません。** GAS の設定画面に登録します。

1. 画面のいちばん左の細い列にある、**歯車⚙「プロジェクトの設定」**を押します。
2. いちばん下までスクロールし、**「スクリプト プロパティ」**の「スクリプト プロパティを追加」を押します。
3. 次の2行を登録して、「スクリプト プロパティを保存」を押します。名前は、大文字・アンダーバーまで**このとおり**に入れてください。

   | プロパティ（名前） | 値 |
   |---|---|
   | `GEMINI_API_KEY` | 手順1で作った API キー |
   | `APP_KEY` | 自分で決めた合言葉（20文字以上の、推測されにくい文字列。[合言葉とは？](#合言葉app_keyとは)） |

### 4. 権限を許可する

1. 左の「＜＞」（エディタ）に戻ります。
2. 上の関数の選択欄で `authorizeTest` を選び、「▶ 実行」を押します。
3. 「承認が必要です」と出たら、自分のアカウントを選んで許可します（「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全でないページ）に移動」で進みます。自分で作ったアプリなので問題ありません）。
4. ドライブに「権限確認用テスト」というドキュメントができます。あとで消してかまいません。

### 5. ウェブアプリとして公開する（デプロイ）

1. 右上の「デプロイ」→「新しいデプロイ」を押します。
2. 歯車の「種類の選択」で「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」を**自分**、「アクセスできるユーザー」を**全員**にして、「デプロイ」を押します。
4. 表示された `https://script.google.com/macros/s/…/exec` の URL をコピーします。

### 6. アプリにつなぐ

1. https://toitoitoi-lab.github.io/sensei-assist/ を開きます。
2. いちばん下の「AIによる指導方針の提案」の枠に、次の2つを入れます。どちらも、そのブラウザにだけ保存されます。
   - 「GAS WebアプリのURL」：手順5の URL
   - 「合言葉」：手順3の `APP_KEY` と同じ文字列
3. 上の「架空の例を入れてみる」→「この内容から27項目を推定する」を押し、スライダーが動けば完了です。

### コードを新しくしたとき

`コード.gs` を貼りかえたあと、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン」で「新バージョン」を選び、「デプロイ」を押します。**「新しいデプロイ」は押さないでください**（URL が変わります）。スクリプト プロパティを変えたときは、デプロイし直す必要はありません。

## 使い方

1. 「架空の例を入れてみる」を押すか、架空の児童生徒の学年・障害種別などを入れます。
2. 様子を文章で書いて「この内容から27項目を推定する」を押すか、スライダーを直接動かします。レーダーチャートで偏りを見ます。
3. 支援者の得意なことを選び、「この内容から指導方針を提案してもらう」を押します。
4. 典型的な支援の要点が出ます。「詳細版を見る」で、目標ごとの手立ての例を見たり、案を足したり、自分の案へのコメントをもらったりできます。
5. 残したいときは「Googleドキュメントにする」か「この内容をJSONで保存」を押します。

## 困ったとき

| 画面に出る言葉 | 原因と対処 |
|---|---|
| GAS のURLを入力してください | 下の「GAS WebアプリのURL」が空です。セットアップの手順6を見てください。 |
| 合言葉が違います | アプリの「合言葉」と、GAS の `APP_KEY` が一字一句同じか確かめてください。 |
| GEMINI_API_KEYが設定されていません | GAS のスクリプト プロパティに `GEMINI_API_KEY` がありません。名前のつづり・前後の空白も確かめてください（手順3）。 |
| APIのレート制限に達しました | 無料枠の回数の上限です。1分ほど待ってから、もう一度押してください。 |
| Gemini APIエラー（モデルが見つからない など） | モデル名が変わった可能性があります。`Code.gs` の `GEMINI_MODEL` を `gemini-flash-latest` に書きかえ、デプロイを更新してください。 |
| 通信エラー | URL の貼りまちがい、またはデプロイの「アクセスできるユーザー」が「全員」になっていない可能性があります。 |

## ほかの人と共有するとき

- 共有するのは、**このページ（GitHub）とアプリの画面の URL** です。
- **自分の GAS の URL、API キー、合言葉は渡さないでください。** 渡すと、相手の入力が自分の API キーで送られ、「Googleドキュメントにする」も自分のドライブに作られます。
- 相手には、この説明書の[セットアップ](#セットアップ)で、相手自身の Google アカウントに GAS を作ってもらってください。

## プライバシーと、使うときの決まり（必ずお読みください）

### 入力した内容の流れ

```
使う人のブラウザ ──▶ 使う人が自分でデプロイした GAS ──▶ Google Gemini API
                                         └──▶ 使う人の Google ドライブ（「Googleドキュメントにする」を押したとき）
```

- **運営者（toi toi toi）は、入力内容を受け取りません。** 運営者のサーバーはなく、アクセス解析も入れていません。
- **Gemini API の無料枠では、送った内容が Google の製品改善に使われ、人（レビュー担当者）が読むことがあります。** Google は無料枠に「機微な情報・個人情報を送らないこと」を求めています。有料枠では、この目的には使われません（[Gemini API 追加利用規約](https://ai.google.dev/gemini-api/terms)）。
- ブラウザに保存するのは、GAS の URL と合言葉だけです（`localStorage`）。ほかの入力は、画面を閉じると消えます。「JSONで保存」「Googleドキュメントにする」を押したときだけ、結果が自分のパソコンやドライブに残ります。
- 画面の表示には、グラフ用のライブラリ（Chart.js）を cdnjs から読みこみます。アプリのページは GitHub Pages で配信しています。どちらも、一般的なアクセス記録（IP アドレスなど）を残すことがあります。

### 使うときの決まり

- **入れるのは、架空の児童生徒の特性だけです。** 実際の児童生徒のデータ（氏名・記号に置きかえたものや、実在の児童生徒の様子をもとにしたものを含む）は入力しないでください。
- **大人が使う道具です。** Gemini API は18歳未満は使えません。児童生徒には使わせないでください。
- 学校で使うときは、所属する教育委員会の**情報セキュリティポリシー**と、生成AIの利用に関する決まりに従ってください。文部科学省の「[初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）](https://www.mext.go.jp/content/20241226-mxt_shuukyo02-000030823_001.pdf)」も参考にしてください。
- 出てくるのは典型的な支援の**例**です。診断や医学的な判断、特定の児童生徒の指導方針を決めるものではありません。AI の出力には誤りが含まれることがあります。

## しくみ

```
index.html（画面）──POST──▶ Code.gs（Google Apps Script のウェブアプリ）──▶ Gemini API
                                    └──▶ Google ドキュメント（出力を保存するとき）
```

| ファイル | 役割 |
|---|---|
| `index.html` | 画面。27項目のスライダー、レーダーチャート、AIへの相談、JSON保存 |
| `Code.gs` | GAS のバックエンド。Gemini への問い合わせと、Google ドキュメントへの書き出し |

APIキーは `Code.gs` には書かず、GAS の「スクリプト プロパティ」に保存します。
